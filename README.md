# EQUILOCK

**EQUILOCK** — escrow-платформа для безпечних P2P та OTC угод **USDT/UAH**. Кошти продавця блокуються на ескроу-рахунку й передаються покупцеві лише після того, як обидві сторони виконали умови угоди. Так жодна сторона не ризикує, що її ошукають.

Це статичний вебсайт без бекенду. Обмін і статуси угод у ньому демонстраційні, а котирування криптовалют завантажуються наживо з CoinGecko API.

## Можливості

- **Головна сторінка:** послуги (P2P, OTC, мультипідпис, арбітраж, API), тарифи, відеогід і карта офісу.
- **Обмін USDT/UAH:** форма створення угоди.
- **Статус угоди:** пошук за номером (наприклад, `status.html?deal=EQ-84920`) і стан системи.
- **Каталог криптовалют:** живі ціни в USD та UAH, зміна за 24 год, графіки за 7 днів, фільтри й пошук.
- **Документація, FAQ, AML/KYC, умови використання та політика конфіденційності.**
- **Дві мови:** українська (корінь сайту) та англійська (папка `en/`).
- **Світла й темна теми** з перемикачем.
- **Адаптивна верстка** для телефонів, планшетів і ПК.

## Технології

- **HTML5:** семантична розмітка, ARIA-атрибути для доступності.
- **CSS3:** [Tailwind CSS](https://tailwindcss.com/) (вже зібраний файл `css/tailwind.css`) і власні стилі в `css/style.css`.
- **JavaScript:** чистий JS без фреймворків і без збирання.
- **Шрифти й іконки:** Manrope, JetBrains Mono, Font Awesome. Усе підключено локально з папки `assets/`.
- **Дані:** [CoinGecko API](https://www.coingecko.com/en/api) для котирувань.


## Як запустити локально

Встановлювати нічого не потрібно.

**Варіант 1.** Відкрийте `index.html` у браузері.

**Варіант 2 (рекомендовано).** Запустіть локальний сервер у папці проєкту:

```bash
# Python 3
python3 -m http.server 8000

# або Node.js
npx serve .
```

Після цього відкрийте у браузері адресу `http://localhost:8000` (для `npx serve` — адресу, яку він покаже в терміналі).

> Для живих котирувань потрібен інтернет. Без нього в каталозі замість цін будуть прочерки, решта сайту працює як звичайно.
